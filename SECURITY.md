
# Security Policy

JARVIS AI takes user privacy seriously.

## API keys

- Never commit API keys to GitHub.
- Never put private credentials in source code.
- Use a secure backend for production API requests.

## Permissions

JARVIS should request permissions only when required.

## User privacy

- Do not collect personal information unnecessarily.
- Do not secretly record audio.
- Do not access private files without permission.
- Let users clear their conversation history.

## Reporting issues

Report security problems privately to the project owner.
Do not publish secret credentials in an issue.
